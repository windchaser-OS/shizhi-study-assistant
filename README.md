# 拾知 · 本地学习助手

围绕已有 Obsidian 仓库构建的个人学习工作台：编辑和检索笔记，整理错题，生成学习摘要、计划与复习卡片，并把照片中的学习内容转录为可审核的文字。

默认笔记仓库位于 `obsidian/universities study program`。首次启动会自动创建空仓库，可以在浏览器和 Obsidian 中使用同一批 Markdown 文件。源码不携带示例笔记、个人笔记或学习记录。

## 获取源码

```powershell
git clone https://github.com/windchaser-OS/shizhi-study-assistant.git
cd shizhi-study-assistant
```

个人笔记库 `obsidian/`、运行数据 `.study-data/`、登录信息、环境配置和依赖缓存均不纳入 Git。使用自己的笔记库时，可以通过 `STUDY_VAULT` 指定其路径。

## 启动

需要 Windows 上的 Python 3.10 或更新版本，以及已安装、可正常使用的 Codex CLI。

1. 双击项目根目录中的 `启动学习助手.cmd`，启动器会打开浏览器；也可以在根目录打开终端运行：

   ```powershell
   python -m study_app.server
   ```

2. 在浏览器打开 <http://127.0.0.1:8765>。
3. 点击「新建笔记」，上传学习资料或填写自己的内容；检查 AI 草稿和分类后保存。已有 Obsidian 笔记库可以通过 `STUDY_VAULT` 连接。

PDF 文本提取使用可选依赖 `pypdf`。需要使用 PDF 导入时，在项目根目录运行：

```powershell
python -m pip install -r requirements.txt
```

数学公式渲染所需的 KaTeX 资源随项目提供，日常启动不需要 Node.js 或 npm，也不依赖在线公式资源。如需重新构建前端依赖资源，先安装 Node.js，再依次运行 `npm ci` 和 `npm run vendor`。

启动服务的终端需要保持运行；在该终端按 `Ctrl+C` 可停止服务。若端口已被其他程序占用，请先关闭之前启动的学习助手。

使用 AI 功能前，请在终端确认 `codex --version` 能运行，并通过 `codex login` 完成 ChatGPT 账户登录。这里使用 Codex CLI 的登录与用量额度，不要求填写 OpenAI API Key。账户可用模型、权限和用量以 Codex 实际显示为准。

本机已用 Codex CLI 0.159.0 验证。应用仅复用 ChatGPT 登录，不会自动使用环境里的 API Key；旧版 CLI 如不支持调用参数，请升级官方 CLI 后重试。

## 可以做什么

- **笔记管理**：浏览、编辑、保存本地 Markdown，导入 `.md`、`.txt` 或可提取文字的 PDF。
- **资料写笔记**：在「新建笔记」中上传课堂图片、PDF、Markdown 或 TXT，可以混合上传最多 6 份资料（合计 12 MB，每份文字文件最多 2 MB）。填写选填的整理要求，点击「根据资料生成笔记」，AI 会结合资料写出含来源说明的学习笔记草稿，并尝试拟定标题。草稿可以直接修改，确认后保存到 Obsidian。暂时关闭窗口会保留本次草稿和资料，重新点击「新建笔记」继续；刷新或关闭网页后未保存的草稿不会保留。也可以只填写正文，让 AI 整理已有内容。
- **笔记自动分类**：生成学习笔记时同时识别学科、笔记类型和最多 5 个标签，手写笔记默认在保存时分类。新笔记按「类型/学科」建议目录保存，例如 `02_错题本/数学/`；手动修改保存位置会保留你的选择。分类结果可以修改，取消「保存时自动分类」可直接保存而不请求分类 AI。打开已有笔记点击「自动分类」，检查后保存分类；编辑已有笔记时也可勾选保存时分类。已有文件保留原路径和双向链接。分类信息写入 Markdown 的 `category`、`subject`、`tags` 属性，在 Obsidian 和浏览器中都可使用；知识库提供类型和学科筛选。历史笔记未明确学科时显示「未分类」，不批量改写。
- **搜索与引用**：对中文和英文文本进行本地词法检索，查看命中的笔记，并在基于笔记的回答中追溯来源。检索依赖用词匹配；找不到时可更换关键词，或先补充笔记。
- **学习整理**：调用 Codex 生成摘要、学习计划和复习卡片，先检查内容再采用。学习计划应由你提供考试时间、可用时间与具体目标。
- **间隔复习**：创建并复习卡片，依据自己的回答反馈安排后续复习。不要把浏览过答案算作已掌握。
- **照片整理**：上传照片，让 Codex 转录；核对公式、符号、题号后再保存为笔记。

PDF 导入提取已有文字层，不提供扫描 PDF 的 OCR。扫描页可以先转为图片，再走照片转录。这里使用轻量的本地词法搜索，未接入向量嵌入，也不依赖 LlamaIndex 或 AnythingLLM。

## 推荐的日常流程

1. 把课堂片段、临时问题或转录结果放到「00_收集箱」。
2. 整理为知识笔记或错题，保留教材/页码/题目来源。
3. 用自己的话写出结论、适用条件与一个反例；把关联笔记用 `[[双向链接]]` 连起来。
4. 从已核对的内容生成摘要或卡片。发现答案不可靠时，回到教材和原题校对。
5. 在浏览器完成到期卡片复习；每周根据错题和实际时间调整计划。

可以在自己的 Obsidian 仓库中创建空白模板。应用不会更改 Obsidian 的模板插件、日记插件或其他配置。

## 本地笔记目录

保存笔记时按分类自动创建所需目录；下列目录属于本地学习资料，不上传 GitHub：

```text
obsidian/universities study program/
├─ 00_收集箱/                     # 待核对和待整理内容
├─ 01_知识笔记/                   # 定义、定理、例题、联系
├─ 02_错题本/                     # 错误原因、正确思路、自测
├─ 03_学习计划/                   # 周计划和复盘
├─ 04_复习卡片/                   # 可读的卡片笔记与编写指引
├─ 05_学习档案/                   # 个人目标、偏好、工作流
└─ 90_模板/                       # 可自行创建的空白模板
```

项目从空知识库开始，所有笔记、卡片和学习记录由实际使用产生。使用自建模板时可标记 `category: template`，避免把模板计入实际错题统计。

## 数据、AI 与隐私

- Markdown 笔记保存在本地，复习等应用数据保存在本地 `.study-data` 目录中的 SQLite 数据库。备份时同时保存笔记仓库和 `.study-data`。学习助手只绑定本机地址 `127.0.0.1`，设计用于个人电脑上的本地使用；不要将此端口直接暴露到公网。
- **点击 AI 功能时，所选文本、用于检索的相关笔记片段或上传的照片会交给 Codex 在线处理。** “本地笔记”不等于“离线模型”。仅提交你愿意发送的材料。
- 本项目经 Codex CLI 调用模型，消耗对应账户的可用额度；没有另建 API Key 付费通道。
- 应用不会自动继承你在 ChatGPT 网页里其他对话的历史或记忆。希望模型知道的课程背景、目标和约束，应在当前请求或相关档案中明确提供。
- AI 调用使用只读执行约束；模型输出回到应用后由你审核、保存。笔记写入由本地服务完成，不让模型直接改写整个仓库。
- Obsidian 自身的同步行为由你的 Obsidian 设置控制；本项目没有更改那些设置。请在重要修改前备份仓库。

AI 可能误读照片、遗漏适用条件或给出错误推导。引用表示答案使用了哪些本地材料，并不等同于已通过事实核验；公式和答案仍需对照原始材料检查。

## 常见问题

**页面打不开**：确认启动终端没有退出，并且地址是 `http://127.0.0.1:8765`，不是 `https://`。

**提示找不到 Codex**：安装或修复 Codex CLI 后，重新打开终端，让新的 `PATH` 生效；先单独确认 `codex --version` 可以运行。

**AI 提示未登录、额度不足或网络错误**：在终端检查 Codex 的实际状态，必要时执行 `codex login`。本地浏览、编辑和搜索笔记不依赖模型成功响应。

**搜索没找到内容**：尝试笔记中实际出现的词，例如「可导」「连续」「绝对值」。当前检索不保证理解所有同义表述。

**照片中的公式不准确**：提高图片清晰度，减少一张图中的内容量，并在保存前人工校对分数线、指数、上下标、正负号和边界条件。

**Obsidian 与浏览器都在编辑同一篇笔记**：先在一个界面保存，再在另一界面重新打开。尽量避免两边同时保存同一文件。

## 开发与配置

`python -m unittest discover -s tests -v` 运行本地测试；测试使用临时仓库和模拟的 AI 返回，不消耗 Codex 额度。`node --check web/app.js` 检查前端脚本语法。实际模型联网调用单独验证，不是自动测试的一部分。

可选环境变量：`STUDY_VAULT` 指定 Obsidian 仓库，`STUDY_DATA_DIR` 指定本地学习数据库目录，`STUDY_CODEX_PATH` 指定 Codex 可执行文件，`STUDY_CODEX_MODEL` 选择账户可用的模型。未设置时使用默认本地目录和 CLI 默认模型。自定义端口使用 `python -m study_app.server --port 8767`。

一次仅执行一个 AI 请求，3 分钟超时后会结束子进程。长篇整理每次处理前 32000 字符，并在结果中提示处理范围；新建笔记的多份文字资料共享 32000 字符，另参考已有草稿的前 16000 字符。长资料应按章节拆分。上传资料的原文件不会附加保存到 Obsidian，生成的笔记会保留来源文件名；请自行保管原始资料。
